# Документация по миграции TamaFi

Эта папка содержит всю документацию, связанную с миграцией проекта TamaFi на целевое устройство **MiiBestOD / Spotpear ESP32-S3-Touch-AMOLED-1.8**.

**Примечание:** Это одно и то же устройство, продается под разными брендами (MiiBestOD, Spotpear) с разными корпусами. Официальная документация доступна на Waveshare Wiki.

## 📁 Содержимое

### Основные документы

1. **MIGRATION_PLAN.md** - Детальный план действий по миграции
   - Фазы миграции
   - Задачи и подзадачи
   - Отметки блокеров
   - Оценка времени

2. **MIGRATION_DIFFERENCES.md** - Различия между текущим кодом и целевым устройством
   - Размеры экрана
   - Ввод (кнопки → тач-экран)
   - Светодиоды → экранные индикаторы
   - Стратегии адаптации

3. **MIGRATION_FEASIBILITY.md** - Оценка возможности миграции
   - Общая оценка (85% - возможна)
   - Анализ компонентов
   - Риски и решения
   - Рекомендации

4. **MIIBESTOD_1.8_AMOLED.md** - Описание целевого устройства MiiBestOD / Spotpear ESP32-S3-Touch-AMOLED-1.8
   - Технические характеристики (45×37×17 мм, 38г, 350mAh)
   - Элементы управления (2 физические кнопки + тач-экран)
   - Библиотеки и драйверы
   - Распиновка

5. **DEVICE_TOP.md** - Сравнение портативных ESP32-S3 устройств
   - Сравнительная таблица устройств
   - Выбор целевого устройства

6. **PET_LOGIC.md** - Логика питомца
   - Состояния (Stage, Mood, Activity, RestPhase)
   - Деградация статов, эволюция, настроение
   - Автономные решения, конечный автомат отдыха
   - Mermaid-диаграммы

7. **CORE_DISTRIBUTION.md** - Распределение по ядрам ESP32-S3
   - Таблицы по ядрам и компонентам
   - Рекомендации по многопоточности
