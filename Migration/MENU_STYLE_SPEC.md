# Спецификация единого стиля меню TamaFi

## 1. Цвета

| Элемент               | Цвет          | Hex      | Использование               |
| --------------------- | ------------- | -------- | --------------------------- |
| Фон экрана            | Чёрный        | 0x000000 | Все экраны                  |
| Фон пункта меню       | Светло-серый  | 0xb0b0b0 | Обычное состояние           |
| Фон выбранного пункта | Серый         | 0x909090 | Подсветка выбора           |
| Текст пункта          | Чёрный        | 0x000000 | На фоне светло-серого      |
| Текст значения        | Чёрный        | 0x000000 | Справа в пункте (Настройки) |
| Шапка: фон            | Чёрный        | 0x000000 | Полоса 18px                 |
| Шапка: разделитель    | Голубой       | 0x00FFFF | Линия под шапкой            |
| Шапка: заголовок      | Белый         | 0xFFFFFF | Название экрана             |
| Шапка: время/батарея  | Белый/голубой | 0xFFFFFF / 0x00FFFF | Как сейчас |

## 2. Типы экранов

### 2.1 Список меню (Меню, Настройки)

- Пункты с возможным значением справа
- Скролл при >N пунктов
- Навигация: UP/DOWN — выбор, OK — действие

### 2.2 Инфо-экран (Статус питомца, Система)

- Пары «метка: значение»
- Секции с заголовками «--- Батарея ---»
- Скролл при длинном контенте
- Только чтение, навигация: OK — назад

## 3. Шапка (единая для всех)

- Высота 18px, чёрный фон
- Заголовок слева (40px отступ)
- Время по центру
- Батарея справа
- Линия-разделитель под шапкой (голубой)

## 4. Реализация

- LVGL для всех меню и инфо-экранов
- Шапка: вариант A — рисуется на Arduino_Canvas до LVGL flush
- LVGL рисует область ниже шапки (y: 18..368)
